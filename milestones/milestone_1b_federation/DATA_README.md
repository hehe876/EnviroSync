`examples/` contains the original locally fetched 2024-01-01..2025-12-31
normalized ERA5/Open-Meteo previews from the user's Milestone 1B folder.
These are environmental data, not an AWS export, and are not live readings.
`preview/` is a generated working directory and ignored by Git.
Use `--output-dir data/examples` with publish to reuse the example previews
ONLY after confirming your buckets, IAM permissions and any AWS charges.
